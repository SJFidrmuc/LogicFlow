# Klávesové zkratky

| Klávesa | Akce |
| --- | --- |
| F1 | nápověda |
| Shift+A | přidat součástku |
| G | přesunout výběr |
| R | otočit o 90° |
| X, Delete | smazat |
| Shift+D | duplikovat |
| Ctrl+C, Ctrl+X, Ctrl+V | kopírovat, vyjmout, vložit (k ukazateli myši) |
| A, Alt+A | vybrat vše, zrušit výběr |
| Esc | zrušit nástroj nebo výběr; v simulaci zpět k úpravám |
| Home | zobrazit celé schéma |
| Tab | otevřít vybraný podobvod, zpět o úroveň výš |
| kolečko myši | zoom |
| prostřední nebo pravé tlačítko + tažení | posun pohledu |
| Ctrl + tažení | začít vodič kdekoli |
| F5 | spustit simulaci (režim simulace) |
| Shift+F5 | zastavit simulaci, zpět k úpravám (stav obvodu zůstane) |
| mezerník | spustit, pozastavit nebo pokračovat |
| šipka vpravo | jeden takt (simulace se pozastaví) |
| Shift+šipka vpravo | krok na další hranu hodin |
| Ctrl+šipka vpravo | krok o celou periodu hodin (na náběžnou hranu) |
| Ctrl+R | restartovat simulaci |
| Ctrl+Z, Ctrl+Shift+Z, Ctrl+Y | zpět, znovu |
| Ctrl+N, Ctrl+O, Ctrl+S | nový, otevřít, uložit |
| Ctrl+Shift+S | uložit jako |
| Ctrl+PageUp, Ctrl+PageDown | předchozí, další pracovní plocha |
| Ctrl+Q | ukončit |
