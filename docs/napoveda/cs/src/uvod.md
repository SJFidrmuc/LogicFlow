# LogicFlow – nápověda

LogicFlow je simulátor logických obvodů pro výuku číslicové techniky. Tato nápověda popisuje práci s programem od prvního obvodu po podobvody a analýzu. Stejný text najdete i přímo v programu pod klávesou **F1**.

Začínáte? Pokračujte kapitolou [Začínáme](zaciname.md), první obvod zvládnete za pět minut.

- Program ke stažení: [www.logicflow-sim.cz](https://www.logicflow-sim.cz)
- Zdrojový kód a hlášení chyb: [GitHub](https://github.com/SJFidrmuc/LogicFlow)
- Verzi programu zjistíte v nabídce **Nápověda → O aplikaci**. Nápověda vždy odpovídá verzi, se kterou byla vydána.

*English version: [Help in English](en/index.html)*

Hledat v celé nápovědě můžete klávesou **S** nebo lupou nahoře. Ikona tiskárny vytiskne celou nápovědu najednou.
