# LogicFlow – Help

LogicFlow is a logic circuit simulator for teaching digital electronics. This help covers working with the program from your first circuit to subcircuits and analysis. The same text is available in the program under **F1**.

New to LogicFlow? Continue with [Getting started](zaciname.md) – your first circuit takes five minutes.

- Download: [www.logicflow-sim.cz](https://www.logicflow-sim.cz)
- Source code and bug reports: [GitHub](https://github.com/SJFidrmuc/LogicFlow)
- Your program version is shown in **Help → About**. The help always matches the version it was released with.

*Česká verze: [Nápověda v češtině](../index.html)*

Press **S** or the magnifier at the top to search the whole help. The printer icon prints all chapters at once.
