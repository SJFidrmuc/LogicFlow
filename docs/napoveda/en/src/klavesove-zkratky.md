# Keyboard shortcuts

| Key | Action |
| --- | --- |
| F1 | help |
| Shift+A | add component |
| G | move selection |
| R | rotate by 90° |
| X, Delete | delete |
| Shift+D | duplicate |
| Ctrl+C, Ctrl+X, Ctrl+V | copy, cut, paste (at the mouse pointer) |
| A, Alt+A | select all, deselect |
| Esc | cancel tool or selection; in simulation back to editing |
| Home | fit the whole schematic |
| Tab | open selected subcircuit, go back one level |
| mouse wheel | zoom |
| middle or right button + drag | pan |
| Ctrl + drag | start a wire anywhere |
| F5 | run the simulation (simulation mode) |
| Shift+F5 | stop the simulation, back to editing (the circuit state stays) |
| Space | run, pause or resume |
| Right arrow | one tick (the simulation pauses) |
| Shift+Right arrow | step to the next clock edge |
| Ctrl+Right arrow | step one whole clock period (to the rising edge) |
| Ctrl+R | restart the simulation |
| Ctrl+Z, Ctrl+Shift+Z, Ctrl+Y | undo, redo |
| Ctrl+N, Ctrl+O, Ctrl+S | new, open, save |
| Ctrl+Shift+S | save as |
| Ctrl+PageUp, Ctrl+PageDown | previous, next workspace |
| Ctrl+Q | quit |
